## 评分维度

每个候选项目按 6 个维度打分，满分 30：

- 市场欢迎度
- 盈利空间
- 竞争格局
- 项目复杂度反向分：越容易做 MVP 分越高
- 内容质量/文章支撑
- 可迭代性

## 当前 MVP 功能

`index.html` 包含四个视图：

- 评分矩阵：展示 20 个候选项目的 6 维评分。
- 刘小排 Top 3：展示最终选择与首版功能。
- 笑来 Top 3：展示最终选择与首版功能。
- 原型工作台：6 个项目的可交互原型。
